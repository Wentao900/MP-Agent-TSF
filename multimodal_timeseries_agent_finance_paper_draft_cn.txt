四、引言末尾正文（可直接粘贴）
====================
基于上述研究缺口，本文聚焦如下核心问题：如何设计一个多模态时间序列Agent，使其在分钟级金融交易场景中，同时实现长时域上的有效决策能力与可解释性。围绕该主问题，本文进一步提出三个子问题：其一，Agent中的记忆与反思机制能否显著提升风险调整后收益（RQ2）；其二，引入可解释约束后，交易性能与解释质量之间是否存在可量化权衡（RQ3）；其三，所提方法在不同市场状态（上涨、下跌、震荡）下是否保持稳定泛化能力（RQ4）。

为回答上述问题，本文的主要贡献如下。第一，提出一种面向分钟级金融交易的可解释多模态时间序列Agent框架，将数值市场信号与文本事件信号统一建模，并在同一决策闭环中联合优化预测与动作选择。第二，设计面向序列决策的记忆—规划—反思机制，使Agent能够基于近期交易轨迹进行策略校正，从而缓解长时域决策中的误差累积问题。第三，构建覆盖“时间片段—模态贡献—决策轨迹”的多层解释接口，并通过反事实分析验证解释的忠实性与稳定性。第四，建立面向真实交易约束的评测协议，在考虑交易成本与滑点的条件下，对不同市场状态进行系统评估，验证方法在收益、回撤与可审计性上的综合优势。

五、第3章正文（方法）
====================
3. 方法总览
本文提出 IMTSA-Agent（Interpretable Multimodal Time-Series Agent），用于分钟级金融场景下的序列决策任务。与“先预测、后规则交易”的两阶段范式不同，IMTSA-Agent将多模态感知、状态记忆、滚动规划与策略反思整合为统一闭环，使模型在每个决策时刻都能同时利用市场微观动态与外部文本事件信息，输出可审计的交易动作。

在时间步 t，系统输入由两部分组成：(1) 数值模态 X_t^(p)，包括价格、成交量及其衍生微结构特征；(2) 文本模态 X_t^(n)，包括与标的相关的新闻、公告或快讯语义表示。给定过去 L 分钟观测窗口 H_t={X_{t-L+1},...,X_t}，Agent输出交易动作 a_t∈{Buy,Sell,Hold}，并可选输出辅助预测头 y_hat_{t+Δ} 以增强状态表征质量。

IMTSA-Agent由四个功能模块构成：Perception（编码并融合多模态输入）、Memory（维护交易与事件记忆）、Planner（滚动决策）、Reflector（周期复盘纠偏）。此外，模型输出时间片段贡献、模态贡献与决策轨迹解释，并通过反事实扰动进行一致性验证。

3.1 符号定义与目标函数
设交易时间索引 t=1,...,T。每个时刻输入向量 X_t=[X_t^(p), X_t^(n)]。数值编码器与文本编码器分别得到隐状态：
h_t^(p)=f_p(H_t^(p)), h_t^(n)=f_n(H_t^(n))。
通过门控融合函数 g(·) 得到联合表征：
z_t=g(h_t^(p), h_t^(n))。
记忆状态更新为 m_t=φ(m_{t-1}, z_t, a_{t-1}, r_{t-1})，其中 r_{t-1} 为上一步收益。策略分布：π_θ(a_t|z_t,m_t)。

总损失：
L = λ1 L_act + λ2 L_pred + λ3 L_exp。
其中 L_act 为动作损失，L_pred 为辅助预测损失，L_exp 为解释一致性约束。

3.2 Multimodal Perception
给定历史窗口，数值序列 H_t^(p)∈R^(L×d_p)，文本序列 H_t^(n)∈R^(L×d_n)。
h_t^(p)=f_p(H_t^(p)), h_t^(n)=f_n(H_t^(n))。
动态门控融合：
α_t=σ(W_α[h_t^(p);h_t^(n)]+b_α),
z_t=α_t⊙h_t^(p)+(1-α_t)⊙h_t^(n)。
该机制可在“消息驱动”与“技术驱动”行情中动态调节模态权重。

3.2.2 Memory for Regime-Aware Decision
显式记忆更新：
m_t=φ(m_{t-1}, z_t, a_{t-1}, r_{t-1})。
事件记忆摘要：
e_t=ψ(e_{t-1}, u_t, Δt)，其中 u_t 为事件语义向量，Δt 为事件时间间隔。最终规划器接收 [z_t; m_t; e_t]。

3.3 Planner 与 Reflector
3.3.1 Receding-Horizon Planner
状态 s_t=[z_t;m_t;e_t]，动作分布 π_θ(a_t|s_t)。
动作平滑项：
L_smooth = Σ_t D_KL(p_t || p_{t-1})。
动作损失：L_act* = L_act + β L_smooth。

3.3.2 Reflection-Driven Policy Adjustment
每 K 步对窗口 W_t={(s_i,a_i,r_i)}_{i=t-K+1}^t 复盘，输出修正信号 δ_t。
修正后策略：p~_t=softmax(o_t+δ_t)。
关注方向误判累积与事件误读偏差，实现局部纠偏。

3.3.3 闭环目标
L_trade = L_act* + η L_ref。
用于验证记忆+反思对风险调整后收益的贡献（RQ2）。

3.4 可解释性建模与反事实验证
3.4.1 三层解释
- 时间层：w_t^time
- 模态层：w_t^mod=[w_t^p, w_t^n]
- 轨迹层：动作转移理由

3.4.2 解释一致性约束
L_exp = max(0, γ - [Δ_high - Δ_low])。
高贡献输入遮蔽应显著降低动作置信，低贡献遮蔽影响较小。

3.4.3 反事实协议
构造时间反事实与模态反事实；验证高贡献扰动导致动作概率与收益显著变化。指标：faithfulness 与 stability（对应RQ3）。

六、第4章正文（实验设置）
====================
4.1 数据构建与时间对齐
数据包含：
(1) 市场数值流（分钟级OHLCV与衍生特征）
(2) 文本事件流（新闻/公告/快讯语义）
仅允许使用在决策时刻 t 之前可获得的信息，杜绝未来信息。

4.2 防未来泄漏切分
采用严格时间切分：train < val < test。
测试阶段顺序单次前向回测，不进行回看式再训练。

4.3 交易执行与成本建模
净收益：
r_t^net = r_t^gross - c|Δq_t| - s|Δq_t|。
同时报告成本前与成本后结果，以成本后指标为主要结论依据。

4.4 指标体系
- 收益风险：累计收益、Sharpe、MDD
- 行为类：胜率、换手率、交易次数
- 预测辅助：方向准确率
- 解释类：faithfulness、stability
多随机种子重复并报告均值±标准差。

八、第6章正文（威胁与伦理）
====================
6.1 内部效度：超参数、训练预算、基线实现一致性风险。
6.2 构念效度：解释一致性不等同于严格因果解释。
6.3 外部效度：跨市场迁移可能退化，需重标定。
6.4 回测偏差：生存者偏差、前视偏差、数据窥探偏差。
6.5 伦理合规：不构成投资建议；需人工复核、风控边界、数据许可合规。

====================
九、第7章正文（结论与未来工作）
====================
7.1 结论
- 统一多模态Agent闭环在成本约束下改善风险收益表现。
- 记忆+反思模块有效缓解误差累积与回撤扩大。
- 三层解释机制在反事实验证中具备可信度与稳定性。
- 跨市场状态下表现更稳健。

7.2 实践启示
- 交易系统应优化执行后风险收益，而非仅优化预测准确率。
- 反思机制是分钟级噪声场景的重要稳健化组件。
- 解释接口应内生到决策流程。

7.3 局限
- 动作空间目前为离散三分类
- 解释评估偏行为一致性，因果性仍有限
- 跨市场/跨资产规模验证待加强

7.4 未来工作
- 连续仓位控制与多资产组合
- 因果增强解释
- 在线自适应学习
- 与合规风控引擎联动部署

====================
十、预期贡献（可放摘要/引言）

3) 提供时间/模态/轨迹三层解释及反事实验证协议，增强可审计性。
4) 建立考虑交易成本与滑点的分钟级评测流程，系统验证跨市场状态稳健性。
